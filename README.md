## Repository Organization

To maintain a clear separation between implementation, experimental evidence, and large reproducibility artifacts, the study resources are distributed between this GitHub repository and a supplementary institutional repository.

### Main Branch

The `main` branch contains the documentation, citation metadata, reproducibility information, dataset-source information, and files required for archival release and DOI registration.

### Code Branch

The [`code`](https://github.com/mahmoudrokaya/Reliability-Aware-Multi-View-Forensic-Evidence-Synthesis/tree/code) branch contains the complete implementation used for the experimental evaluation, including data preparation, semantic evidence representation, reliability estimation, FERF, forensic reasoning, confidence estimation, and evaluation procedures.

### Results Branch

The [`results`](https://github.com/mahmoudrokaya/Reliability-Aware-Multi-View-Forensic-Evidence-Synthesis/tree/results) branch provides the principal experimental outputs and an index to the experiment-specific results.

The experimental results are organized into dedicated branches:

| **Experiment** | **Description** | **Branch** |
| --- | --- | --- |
| 1 | Dataset preparation and integrity verification | `results/01-dataset-preparation` |
| 2 | Conventional baseline models | `results/02-baseline-models` |
| 3 | Framework and multi-view validation | `results/03-framework-validation` |
| 4 | Component ablation and evidence degradation | `results/04-ablation-and-degradation` |
| 5 | Cross-dataset validation | `results/05-cross-dataset-validation` |
| 6 | Computational efficiency and scalability | `results/06-computational-efficiency` |
| 7 | Repeated-CV statistical analysis | `results/07-statistical-analysis` |
| 8 | Final results consolidation | `results/08-final-results-consolidation` |

Experiment 8 is a **results-consolidation stage**. It does not perform additional model training or introduce new experimental observations. It consolidates validated outputs from the preceding experiments for final analysis and reporting.

See [`RESULTS_INDEX.md`](https://github.com/mahmoudrokaya/Reliability-Aware-Multi-View-Forensic-Evidence-Synthesis/blob/main/RESULTS_INDEX.md) for a detailed mapping between experiments, result branches, and reported outputs.

### Supplementary Reproducibility Archive

Some reproducibility artifacts generated during the experiments are too large for practical storage in this GitHub repository. Several individual files exceed 25 MB, and the complete collection of these artifacts exceeds 2.1 GB.

Therefore, the GitHub repository contains the complete experimental code and principal reported results, while the larger experimental artifacts required for detailed verification and reproduction are maintained separately in the **Supplementary Reproducibility Archive** hosted through the institutional storage service of Taif University.

The supplementary archive includes, where applicable:

- saved trained models;
- train/validation/test split files and indices;
- per-view prediction and probability outputs;
- experiment and execution logs; and
- additional large intermediate reproducibility artifacts generated by the experimental pipeline.

The archive is available at:

**[Supplementary Reproducibility Archive – Taif University](https://taifedusa-my.sharepoint.com/:f:/g/personal/mahmoudrokaya_tu_edu_sa/IgDHi-yD36I6Spl_2xT-Y4RDAanzJi8hVqgqKH-6oBUtsEE?e=N4O6Cu)**

This separation is based solely on storage and file-size considerations. The GitHub repository and supplementary archive together constitute the reproducibility resources associated with the study.

## Reproducibility

The reproducibility resources are structured so that the relationship between the implementation and reported experimental evidence can be traced as:

**Dataset → Preparation → Experiment Code → Experimental Artifacts → Consolidated Result**

The exact scripts used for the experiments are retained in the `code` branch. Principal experimental results are retained in the corresponding experiment-specific GitHub result branches.

Because the complete collection of generated reproducibility artifacts exceeds 2.1 GB and includes individual files larger than 25 MB, large artifacts are provided separately through the institutional **Supplementary Reproducibility Archive**:

**[Access the Supplementary Reproducibility Archive](https://taifedusa-my.sharepoint.com/:f:/g/personal/mahmoudrokaya_tu_edu_sa/IgDHi-yD36I6Spl_2xT-Y4RDAanzJi8hVqgqKH-6oBUtsEE?e=N4O6Cu)**

The supplementary archive contains the large experimental artifacts required for detailed verification, including saved models, data-split files, per-view predictions, run logs, and associated experimental outputs that cannot reasonably be maintained directly in the GitHub repository.

Detailed reproduction instructions are provided in:

[**`REPRODUCIBILITY.md`**](https://github.com/mahmoudrokaya/Reliability-Aware-Multi-View-Forensic-Evidence-Synthesis/blob/main/REPRODUCIBILITY.md)

The software environment is documented through:

- `requirements.txt`
- `environment.yml`

Where applicable, fixed random seeds, validation-controlled parameter selection, common dataset partitions, and leakage-safe preprocessing are used to support reproducibility.

The held-out test partitions are not used to fit predictive parameters, reliability coefficients, evidence-view weights, decision thresholds, or confidence parameters.
